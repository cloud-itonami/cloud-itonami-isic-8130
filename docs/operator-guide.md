# Operator Guide

## First Deployment
1. Register operator, service territory, applicator-license and
   irrigation-compliance scope, crews and robots.
2. Import existing client treatment and service history.
3. Run read-only licensing-scope and mowing/trimming/irrigation-
   monitoring robot mission dry-runs.
4. Configure safety-class allowed sets and human sign-off paths.
5. Publish a dry-run follow-up record and audit export.

## Minimum Production Controls
- applicator-license and irrigation-compliance-scope validation
  before any chemical-application or irrigation-change dispatch
- governor gate on every robot action before dispatch
- human sign-off for :high/:safety-critical actions (an out-of-scope
  chemical application, an unverified irrigation change, an
  unverified follow-up record)
- evidence-backed follow-up records
- audit export for every dispatch, sign-off and follow-up record
- backup manual landscape-care process

## Certification
Certified operators must prove robot-safety integrity, applicator-
license/irrigation-compliance discipline, evidence-backed follow-up
records and human review for dispatch-affecting actions.
